Black Box: first ResNet-18 results (fold 0, seed 1)

First look at how well a neural network recognises the speaking style of a voice it has never heard. One fold, one seed, one test actor: a first result, not the final one.

How to read the numbers. Accuracy = share of test clips whose style was guessed right. Macro-F1 = a score from 0 to 1 that averages how well each of the 7 styles is recognised, so every style counts equally. Guessing at random gives about 14% accuracy (1 in 7). Precision of a style = when the model says "sad", how often it really is sad. Recall of a style = of all truly sad clips, how many the model found.

1. What we trained

  • Model: ResNet-18 (an image-recognition network) reading the spectrogram as a 1-channel picture of 128 frequency bands x 400 time steps (4 seconds).
  • Run A starts from weights pre-trained on ImageNet (photos); run B starts from random weights. Everything else is identical.
  • Optimiser AdamW, learning rate 0.0003 (A) and 0.001 (B), weight decay 0.0001, cosine schedule, batch size 32, at most 30 epochs, early stopping after 6 epochs without improvement, no data augmentation, mixed precision.
  • The checkpoint with the best validation macro-F1 is kept; the test set was used once, at the end.
  • Fold 0, seed 1. Test actor: ex01, whose voice the model never heard during training.

3. Learning curves

Both models learn the training data almost perfectly, and both reach about 99% on validation (run A 0.994, run B 0.991 macro-F1). Run A gets there faster: 0.94 after 2 epochs, against 0.75 for run B. Remember that validation uses the same 3 voices as training.

On the new voice (ex01) the scores drop sharply: run A (pretrained) reaches 54.4% accuracy and macro-F1 0.507; run B (from scratch) reaches 36.1% and 0.342. Both are clearly above chance (about 14%), and run A is clearly better than run B, so in this single run ImageNet pretraining helps. The large gap between validation (about 99%) and test means the models recognise styles very well in voices they know, but much less well in an unknown voice. For run A, whisper (100% recall), sad (89%) and laughing (87%) carry over to the new voice; confused (14%), default (15%) and happy (13%) barely do.

Most mistakes go in one direction: the model calls ex01's clips "sad". 78% of ex01's confused clips and 71% of ex01's default clips are labelled sad, and so are 39% of the happy and 34% of the enunciated clips. Only 28% of the clips the model calls sad are really sad. Happy is also confused with laughing (22% of happy clips). In plain words: for this actor, the model's idea of "sad" covers a large part of ordinary speaking. Run B shows the same pull towards sad, even stronger (80% of default and 72% of enunciated clips). These numbers do not tell us why; the explanation methods (Grad-CAM, Integrated Gradients, LIME) are the tool to look into that. A quick check of average loudness found no obvious difference between ex01 and the other actors for these styles.

6. Shortcut check: can clip length alone do this?

Slow styles fill more of the 4 second window, so length carries some information about the style. A simple model that sees only the clip length (seconds of real audio in the window, and whether the clip was cut at 4 s) shows how far that alone gets.

Length alone does very little: the length-only model reaches 20.4% accuracy and macro-F1 0.148, only a little above chance (14.3%). It mostly recognises enunciated (63% recall, the slowest style) and partly default (44%). The ResNet (54.4%) is far above it, so its result cannot be explained by clip length alone. (This does not prove the ResNet ignores length; it only shows length by itself is weak.) Cropped clips (longer than 4 s) are recognised more often than uncropped ones by run A (60.7% against 51.3%); run B shows no such difference (35.3% against 36.5%). Cropped clips are more often from slow styles such as enunciated, laughing and confused, so this difference partly reflects which styles they are. The "most common style" row is close to chance because all styles are almost equally frequent in training; its style (confused) is picked by a near-tie.

7. Caveats

  • Only one test actor (ex01). Each actor is tested in a different fold; the other 3 folds may give quite different numbers.
  • One seed. Repeating with another seed can change the numbers by a few points; the plan uses 2 seeds.
  • One fold of four. The real result is the average over all 4 folds and 2 seeds, still to come.
  • Pretrained against from-scratch was compared on this single fold and seed only.
  • Validation (same voices) is not a good guide to test (new voice) here: about 99% against 54%. Choosing the checkpoint on validation may therefore not pick the best model for new voices.
  • 4 actors in total is a very small number of voices to learn from.
